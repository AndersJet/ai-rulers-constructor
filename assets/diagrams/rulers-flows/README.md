# README 流程图

绿地初始化、棕地初始化和任务规则加载各提供中英文静态 SVG，与首次发布的使用说明配套。

初始化图展示默认 init-plan/init-apply 的工程与业务证据发现、最小候选准备、集中审阅、采纳和验证；直接子模块由同一入口编排，未初始化模块保留待接入。任务图展示已知选择直接 load、未知范围通过 Context/INDEX 发现，以及执行反馈进入按需维护的路径。

内容依据为 Skill 的 discovery、initialization、generation、activation、maintenance 和 rule-quality references，以及运行态入口和规则加载实现。图示只说明规则流程，不表示生产操作授权。

流程变化时同步中英文图文；交互图与验证凭据须绑定实际源码提交，重新生成并审阅后交付。
