# 最低安全与完成约束

```yaml
metadata:
  applies_to:
    - "**/*"
  trigger_keywords:
    - core
  must_load_with: []
```

- 保留无关人工修改；凭据、隐私和生产数据使用项目既有保护方式。
- 按用户授权范围工作；生产、破坏性或不可逆操作需要针对确切动作的授权。
- 外部输入在系统边界校验，沿用项目的认证、授权和审计机制。
- 以运行态 Context 判断有效画像、领域与下一步。异常时仅执行诊断和恢复，不从原始 State（RULERS_STATE.json） 自行升级权限。
- 区分 observed 实现事实、approved 设计决定和未确认假设；假设不能成为生效约束。
- 行为变更使用能验证目标行为的测试；无法执行时报告替代验证、未覆盖范围及原因。
- 交付声明与实际验证一致；报告失败、跳过项及剩余风险。
- 规则维护通过 ai-rulers-init 的候选差异流程更新正文、索引和状态，保留用户定制及删除决定。
